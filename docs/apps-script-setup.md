# Этап 3 — Google Таблица и приёмник заявок

Сайт отправляет заявку в Apps Script через скрытый HTML-мост. Мост принимает сообщения только с опубликованного домена сайта, вызывает серверную функцию `saveLead()` и возвращает форме подтверждение. Это позволяет не передавать имя, телефон и e-mail через GA4 и дождаться результата сохранения.

## Создание проекта Apps Script

1. Откройте [script.google.com](https://script.google.com/) под своим Google-аккаунтом и создайте новый проект `Кварцит — приём заявок`.
2. Замените содержимое файла `Code.gs` кодом из `apps-script/Code.gs`.
3. Нажмите **+** → **HTML**, назовите файл `Bridge` и скопируйте содержимое из `apps-script/Bridge.html`.
4. В списке функций выберите `setupLeadSheet` и нажмите **Выполнить**. При первом запуске Google попросит разрешить этому скрипту создать таблицу и записывать заявки. После запуска ссылка на таблицу появится в журнале выполнения. Скрипт создаёт таблицу `Кварцит — заявки`, лист `Заявки`, заголовки и фильтр. Часовой пояс таблицы — Москва.

## Публикация

1. Нажмите **Развернуть** → **Новое развертывание**.
2. Выберите тип **Веб-приложение**.
3. Укажите выполнение от имени своего аккаунта. Для учебного публичного сайта выберите доступ **Все** (название пункта может отличаться).
4. Нажмите **Развернуть**, пройдите авторизацию и скопируйте URL веб-приложения, заканчивающийся на `/exec`.
5. В `js/config.js` вставьте этот URL в `window.KVARCIT_LEAD_ENDPOINT`.
6. Опубликуйте обновление сайта через GitHub/Vercel.

Публичный веб-приёмник сможет добавлять строки в созданную таблицу. В Apps Script проверяются обязательные поля, телефон, согласие и домен; повторный номер заявки не записывается второй раз. В самой форме остаётся обязательная галочка согласия.

## Проверка

После публикации отправьте форму с вымышленными тестовыми данными и согласием. Убедитесь, что появилась строка в листе `Заявки`, а сайт открыл `thanks.html`. Не используйте для проверки настоящий телефон или e-mail.

После проверки `generate_lead` появится среди событий GA4; его можно будет отметить как ключевое. Параметры UTM сохраняются в листе отдельно от аналитических событий.
